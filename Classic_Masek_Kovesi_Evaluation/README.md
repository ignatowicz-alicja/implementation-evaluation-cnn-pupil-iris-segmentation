# CASIA-IrisV1 Classical Segmentation and Biometric Evaluation

Portable evaluation package for the classical Masek/Kovesi iris-recognition pipeline used in the experiments supporting the article **“Implementation and Evaluation of CNN for Pupil and Iris Segmentation on Devices with Varying Computational Resources”** and the related engineering thesis.

This repository component evaluates classical pupil/iris localization, segmentation quality, processing time, feature extraction, and top-1 biometric identification on **CASIA-IrisV1**. It deliberately separates the project-authored evaluation code from the original third-party implementation and from restricted dataset files.

## Evaluated pipeline

The package tests the following stages:

1. pupil boundary detection;
2. outer iris boundary detection;
3. upper- and lower-eyelid localization;
4. eyelash/noise masking;
5. iris normalization;
6. iris-code encoding;
7. Hamming-distance matching and top-1 identification.

The wrappers record the time of individual stages and the complete segmentation/feature-extraction time.

## Segmentation evaluation

The detected pupil circle is converted into a binary mask and compared with the ground-truth pupil mask. The following metrics are saved per image and summarized for the dataset:

- Intersection over Union (IoU);
- Dice coefficient;
- pixel accuracy;
- precision and recall;
- specificity;
- false-positive and false-negative rates;
- TP, FP, FN, and TN pixel counts.

Default diagnostic thresholds are:

- bad segmentation if `IoU < 0.50`, or
- bad segmentation if `Dice < 0.65`.

These thresholds control diagnostic-file export only; they do not change the metric values.

## Biometric identification protocol

For each identity, the first successfully processed image is assigned to the gallery and the remaining successfully processed images are used as probes. Each probe is compared with all gallery templates using Hamming distance. The closest template determines the top-1 prediction.

The scripts save:

- true and predicted identity;
- best Hamming distance;
- correctness of each top-1 decision;
- total matching time;
- mean, minimum, and maximum time of an individual comparison.

python -m pip install -r requirements.txt

## Preparing external code

Place the external implementation under:

```text
third_party/Iris-Recognition-master/
├── python/fnc/
└── matlab/fnc/
```

The Python wrapper expects these modules:

```text
fnc.boundary   -> searchInnerBound, searchOuterBound
fnc.segment    -> findTopEyelid, findBottomEyelid
fnc.normalize  -> normalize
fnc.encode     -> encode
fnc.matching   -> calHammingDist
```

The MATLAB wrapper expects the corresponding original functions, including normalization, encoding, segmentation, and Hamming-distance matching routines.

The classical approach is based on the work of Libor Masek and Peter Kovesi. Consult the official project and source-code terms before redistributing third-party files:

- <https://www.peterkovesi.com/studentprojects/libor/>
- <https://www.peterkovesi.com/studentprojects/libor/sourcecode.html>

## Preparing CASIA-IrisV1 and masks

The repository does not contain biometric images. Obtain CASIA-Iris data directly from the Institute of Automation, Chinese Academy of Sciences, and follow its terms:

- <https://english.ia.cas.cn/db/201610/t20161026_169399.html>

Place original BMP images in:

```text
data/CASIA1_BMP/
```

Place optional JPG-converted images in:

```text
data/CASIA1_JPG/
```

Place binary pupil masks in:

```text
data/ground_truth/pupil_masks/
```

The pupil must be foreground. The loader automatically handles masks with an inverted black-pupil/white-background convention when the foreground area indicates inversion.

## Running the Python evaluation

### Windows PowerShell

```powershell
.\scripts\run_python.ps1
```

### Linux

```bash
./scripts/run_python.sh
```

### Direct command

```bash
python src/python/run_casia_full_eval_python.py \
  --dataset bmp \
  --code-dir third_party/Iris-Recognition-master/python \
  --bmp-dir data/CASIA1_BMP \
  --gt-dir data/ground_truth/pupil_masks \
  --output-dir results/python
```

A quick configuration test can be run with:

```bash
python src/python/run_casia_full_eval_python.py --dataset bmp --max-images 10
```

Available dataset modes are `bmp`, `jpg`, and `both`.

## Running the MATLAB evaluation

Open and run:

```text
src/matlab/run_casia_full_eval_matlab.m
```

The script resolves paths relative to the repository root. If a different local layout is required, edit only the configuration block at the beginning of the file.

## Generated outputs

For each dataset variant, the scripts generate:

| Output | Description |
|---|---|
| `per_image_segmentation_and_feature_times.csv` | Per-image timings, detected circles, segmentation metrics, statuses, and errors. |
| `identification_top1_results.csv` | Probe-level top-1 matching results and timing. |
| `summary.txt` | Human-readable experiment summary. |
| `summary.json` / `summary.mat` | Machine-readable summary. |
| `predicted_pupil_masks/` | Binary masks generated from detected pupil circles. |
| `bad_segmentations_overlays/` | Diagnostic TP/FP/FN overlays for low-quality cases. |
| `missing_gt_overlays/` | Images without a matched ground-truth mask. |
| `failed_processing/` | Diagnostic files for exceptions or failed segmentation. |
| `worst_examples/` | Worst cases ranked by IoU. |
| `hist_*.png`, `mean_stage_times.png` | Metric and runtime plots. |

## Reproducibility and scope

This package reproduces the **CASIA-IrisV1 classical-method evaluation workflow**. It does not include:

- the CASIA dataset;
- the manual ground-truth masks in this prepared archive (the project may add them separately);
- third-party implementation files unless their redistribution is separately permitted;
- generated experimental results;
- U-Net training code, which belongs to a separate repository component.

Absolute user paths, usernames, cached bytecode, and local-machine metadata were removed from the public version.
